# EcoVision Sentinel -- full pinned environment
#
# This file is installed into BOTH environments by setup.bat:
#   .venv/      -> hot-reload development (run_dev_system.bat)
#   python-env/ -> the runtime bundled into the portable build (build_release.bat)
#
# It is a full lock (transitive deps included), not a top-level wishlist,
# because python-env/ ships to end users and has to be reproducible.
#
# The extra index below is REQUIRED: plain `torch==2.5.1` from PyPI is the
# CPU build. Only the PyTorch cu121 index serves the +cu121 wheels this
# project actually runs on. setup.bat passes the same flag on the command
# line; keeping it here means a bare `pip install -r requirements.txt` also
# gets the right build instead of silently installing CPU torch.
